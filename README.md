## Import into Stitch

Use this repository URL. Read the root [DESIGN.md](DESIGN.md), then select **warehousebay** or **repairbay** explicitly. Each folder includes readable Markdown descriptions of the screen layouts and text, CSS tokens, original SVGs and per-item JSON snapshots.

The applications are intentionally kept separate. No application source code, production records, database, server configuration, credentials or browser bridge is included.

Exports dated 9 November 2026. The source Figma files were not modified. This is a design reference export, not a native .fig backup. Fonts are referenced rather than bundled. Public visibility does not grant an additional open-source licence.
