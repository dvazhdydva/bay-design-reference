# repairbay

Static design references exported from Figma on 9 November 2026.

- Start with [DESIGN.md](DESIGN.md).
- Browse [SCREENS.md](SCREENS.md) for 116 screens, components and variant boards.
- `screens/` contains readable Markdown descriptions of each screen's layout and text. These are provided for tools that do not accept JSON or SVG uploads.
- `svg/` contains visual references with text preserved.
- `json/` contains the corresponding complete per-item layer/property snapshots.
- `design-tokens.css` contains observed design values. `named-tokens.css`, when present, contains native named tokens and text-style classes.
- `styles-and-variables.json` preserves local styles and variables.
- Open `index.html` locally for a visual catalogue.

These are design mockups and sample content, not live stock, repairs, application source code or a database export. JSON is a property snapshot, not a native .fig backup; CSS is reference material, not a production application stylesheet.

The large combined JSON is intentionally represented by the equivalent per-item files in `json/` to keep repository imports manageable. Original complete archives remain local.
